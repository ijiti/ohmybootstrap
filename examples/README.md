# examples/

- `CLAUDE.md` — a filled-in example of `claude/CLAUDE.md.template` resolved for a hypothetical Python web app called "tilt". Illustrative only.
- `tasks.jsonl` — empty scaffold. Format: one JSON object per line, fields: `subject` (string), `description` (string), `status` (one of `pending`/`in_progress`/`completed`), `owner` (optional string), `blockedBy` (optional array of subject strings).
